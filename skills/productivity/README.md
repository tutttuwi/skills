# Productivity

コード以外の日常ワークフローで使うスキル。

## User-invoked

- [put-know](./put-know/SKILL.md): AIエージェントとの会話で得た学びを、GitHub/GitLabリポジトリ (PR/MR) かローカルディレクトリに `knowledge/yyyy-mm-dd_<概要>.md` として登録する。過去のナレッジには Obsidian リンクで関連づける。
- [output-from-know](./output-from-know/SKILL.md): 貯めたナレッジから記事を生成し、指定したリポジトリの指定ディレクトリに PR/MR で出力する。

## Model-invoked

- [get-know](./get-know/SKILL.md): 貯めたナレッジを検索し、前にも同じ話があったかをすぐ答える。
- [setup-know](./setup-know/SKILL.md): ナレッジ系スキルの共通基盤。保存先を聞いて設定ファイルに登録し、リポジトリへの変更を PR/MR で公開する。
