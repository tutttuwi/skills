# Get Know

`put-know` で貯めたナレッジを探し、「前にも同じようなことがあったか」をすぐ答える。読み取り専用で、何も書き換えない。

ナレッジの構造は次のとおり。検索はこの構造を使う。

- `knowledge/yyyy-mm-dd_<概要>.md` に一件ずつ入っている。日付はファイル名の先頭にあるので、名前順がそのまま時系列になる。
- 先頭の frontmatter に `title` と `tags`、本文の `## 要約` に結論がある。
- `## 関連` に、関連する過去ナレッジへの Obsidian リンク (`[[ファイル名]]`) がある。

引数は `/get-know <探したいこと>`。ユーザーの質問や、いまの作業のエラー文、技術名をそのまま検索語の元にしてよい。

## 手順

### 1. 保存先を解決する

Skill ツールで "setup-know" を呼び、「ナレッジの保存先を解決する」(節 A) を実行する。

- 呼び出し元 (`put-know` など) がすでに保存先を決めているときは、それを使う。もう一度聞かない。
- 保存先が未設定なら、`setup-know` がユーザーに聞いて設定する。
- リポジトリの場合は、`setup-know` が読み取り用の clone を最新にする。取得できず手元のコピーを使うときは、その旨を結果に書く。
- 既定以外の登録先もまとめて探したいと言われたら、設定ファイルの `destinations` を全部順に調べる。

### 2. 検索語を決める

質問から、探す手がかりを三〜六語に絞る。

- 技術名、ツール名、エラー文の特徴的な部分、症状を表す語。
- 言い換えや表記ゆれも足す (例: `docker` と `Docker`、`キャッシュ` と `cache`、日本語と英語)。大文字小文字は区別されない。
- 汎用的すぎる語 (「エラー」「設定」だけ) は外す。

### 3. 検索する

スキルのディレクトリにある補助スクリプトを使う。ナレッジの置き場は、手順 1 で返ってきた「作業コピー」のパス。

```bash
bash <スキルのディレクトリ>/scripts/search-knowledge.sh search <作業コピー> <語1> <語2> ...
bash <スキルのディレクトリ>/scripts/search-knowledge.sh list <作業コピー> 10     # 最近の十件
bash <スキルのディレクトリ>/scripts/search-knowledge.sh links <作業コピー> <ファイル>  # 関連リンクをたどる
```

- `search` は、ファイル名、タイトル、タグ、本文の一致で点数をつけて、関連度順に表示する。
- 検索語を変えて二、三回試してから「見つからない」と判断する。一回で諦めない。
- 手がかりがなくて「最近何を貯めたか」を見たいときは `list` を使う。
- スクリプトが使えない環境では、`grep -ril` と `ls` で同じことをする。

### 4. 候補を読んで絞る

点数の高い上位三〜五件は、frontmatter と `## 要約` と `## 学び` を読んで、本当に今の話に関係するかを判断する。

- ファイル名やタグの字面が似ているだけで、中身が別の話なら外す。
- 良い候補は `links` で、`## 関連` のリンク先と、そのファイルを参照している側も見る。一段だけたどり、深追いしない。
- 同じ話題が時期をまたいで複数あるときは、新しいものを優先し、古いものとの違い (更新された結論) を添える。

### 5. 答える

見つかったときは、候補ごとに次を書く。

- タイトルと日付、Obsidian のリンク (`[[ファイル名]]`)、リポジトリならそのファイルの場所
- 要約と、今の質問にどう関係するか
- そのまま使えるコマンドや結論があれば、その部分

最初に「前にも同じ話があった / 近い話はあった / なかった」を一行で言い切り、そのあとに詳細を並べる。

見つからなかったときは、「探した場所と検索語」を添えて、見つからなかったと正直に伝える。推測で埋めたり、似ているだけのものを「あった」と言ったりしない。いまの会話に残す価値のある学びがありそうなら、ユーザーに `/put-know` の実行を促す (勝手に登録しない)。

## 守ること

- 読み取り専用。ナレッジの作成、変更、コミット、push はしない。
- 見つけた内容を要約するとき、元のナレッジに書かれていないことを足さない。
- 結果に秘密情報らしき文字列が含まれていたら、そのまま出さずに、ナレッジ側に残っていることを知らせる。
