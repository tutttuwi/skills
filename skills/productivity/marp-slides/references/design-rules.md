# スライド共通のデザインルール

- 1枚に主メッセージを1つ置く。表紙・章扉・問いかけ以外は、タイトルからそのページの要点が読めるようにする。
- 既定のキャンバスは16:9、1280×720px。明示指定の 4:3 は `size: 4:3` をフロントマターに記載する。余白は48〜64pxを目安にする。
- タイトル36〜48px、本文24〜28px、注釈16〜18pxを目安にする。短い表紙や数字は大きくし、情報過多ならページを分ける。端末が異なる場合はフォントの代替と改行を確認する。
- 色は意味に対応させ、通常のアクセントは1〜2色。状態や系列はラベル、線種、形も使って区別する。凡例と本文の用語を揃える。
- 並列は横、階層は縦、時間は左から右を軸にする。依存や因果は線と矢印、必要なら接続ラベルで明示する。
- 図が情報を伝えるときに使う。アイコンのサイズと線幅を揃え、写真は見せる対象や構図に理由があるものを使う。
- グラフには対象・単位・期間、必要に応じて凡例・母数・出典を添える。推計、仮の値、欠損、実績を区別する。
- コードは必要な行に絞り、言語を指定する。実行例には前提と確認結果が分かる情報を添える。
- 目的ごとの展開を維持したまま、ページの情報関係に応じてフォーマットを変える。テーマは `references/themes/<ID>.css`、共通レイアウトとスタイルトークンは `references/themes/base.css`。
- Marp のコメントディレクティブで局所指定するものは `_class` のようにアンダースコアを付ける。複数クラスは `<!-- _class: "hero center" -->` のように指定する。HTML 内では Markdown の解釈に頼らず、必要な見出し・リストを HTML タグで書く。
